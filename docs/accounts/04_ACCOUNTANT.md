## 📝 Journal Entry Workflow

The accountant's primary workflow is creating and posting balanced journal entries:

### How It Works

1. **Set Entry Date** — Select the accounting period date
2. **Add Reference** — Auto-generated (e.g., `JE-2026-0815`) or manual
3. **Enter Description** — Describe the transaction
4. **Add Journal Lines** — Select accounts, enter debit/credit amounts
5. **Verify Balance** — System shows:
   - `Total Debit: EGP X`
   - `Total Credit: EGP X`
   - `Balanced ✓` or `Difference: EGP X`
6. **Post Entry** — Post button only enabled when entry is balanced
